## Install

server
http://localhost:4000/graphql

```
cd ./server
npm install
npm run start:all
```

client

**user-app**

http://localhost:3001

```
cd ./client/user-app
npm install
npm run deploy
```

**shell-app**
壳，包容所有模块
http://localhost:3000

```
cd ./client/shell-app
npm install
npm run dev
```
